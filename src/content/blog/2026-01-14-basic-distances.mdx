## 1. Euclidean Distance ($l2$)

### Origin

The Euclidean distance originates from classical Euclidean geometry as formalized in *Elements* by Euclid.
It represents the straight-line distance between two points and became algebraically formalized with the development of analytic geometry and linear algebra.

### Definition

For vectors $x, y \in \mathbb{R}^d$,

$$
d_2(x,y)=||x-y||_2=\big(\sum^d_{i=1}(x_i-y_i)^2\big)^{1/2}.
$$

This is a true metric induced by the $l2$ norm and is invariant under orthogonal transformations (rotations).

### Implementation

#### Python
```python
import numpy as np
np.linalg.norm(x - y, ord=2)
```

#### R
```r
sqrt(sum((x - y)^2))
```

### Usage

#### Natural distance under Gaussian assumptions.
- In linear regression, ridge regression, and many probabilistic models, minimizing squared Euclidean distance is equivalent to maximizing the Gaussian log-likelihood under i.i.d. noise assumptions.
- This statistical optimality explains why $l2$-based objectives are ubiquitous in classic learning algorithms.

#### Prototype-based learning and clustering
- In K-means clustering, the centroid minimizes the sum of squared Euclidean distances to data points.
- This property makes Euclidean geometry particularly well-suited for algorithms based on averaging.

#### Representation learning and embedding space
- Euclidean distance is often used to measure similarity between embeddings.
- Losses such as contrastive loss and triplet loss implicitly shape the embedding space to be Euclidean, leading to spherical level sets of equal similarity.

## 2. Manhattan / Cityblock / Taxicab Distance ($l1$)

### Origin
Named after grid-based city layouts such as Manhattan.
In math, $l1$ norms are fundamental in functional analysis.

### Definition

$$
d_1(x,y)=||x-y||_1=\sum^d_{i=1}|x_i-y_i|.
$$

### Implementation

#### Python
```python
np.linalg.norm(x - y, ord=1)
```

#### R
```r
sum(abs(x - y))
```

### Usage

#### Sparsity and feature selection
- $l1$ distance and $l1$ regularization play a critical role in sparse modeling.
- In LASSO and compressed sensing, $l1$ penalties encourage solutions with many exact zeros.

#### High-dimensional and sparse data settings
- For sparse feature vectors, such as text representations or count-based features, Manhattan distance often provides more meaningful similarity measures than Euclidean distance.

## 3. Chebyshev / Supremum / Chessboard Distance ($l\infty$)

### Origin
Chebyshev distance is closely tied to the approximation theory which began in the 1850s.
The goal is to minimize the *maximum* error over a domain rather than the average error.
$$
||f-p||_{\infty}=\sup_{x\in[a,b]}|f(x)-p(x)|
$$
This supremum norm measures the worst-case deviation between the target function and its approximation.

### Definition
$$
d_{\infty}(x,y)=||x-y||_{\infty}=\max_i|x_i-y_i|.
$$

### Implementation
#### Python
```python
np.linalg.norm(x - y, ord=np.inf)
```

#### R
```r
max(abs(x - y))
```

### Usage

#### Worst-case and robust optimization
- Chebyshev distance is appropriate when system performance is governed by the largest deviation in any dimension.
- In constraint satisfaction, safety-critical systems, and robust design, $l \infty$ captures the idea that a single large violation is unacceptable.

## 4. Minkowski Distance ($l$p)
### Origin
Introduced by Hermann Minkowski in his geometric framework in the late 19th century.
His work focused on applying geometric reasoning such as convex bodies, lattices, and volumes.
The $l$p family of norms emerged as a unifying class that includes $l1, l2$ and $l \infty$ as special cases.
The Minkowski inequality, a generalization of the triangle inequality, formalized the conditions under which these norms define valid metrics.

### Definition
$$
d_p(x,y)=||x-y||_p=\big( \sum^d_{i=1}|x_i-y_i|^p \big)^{1/p}, p\geq 1.
$$

### Implementation
#### Python
```
np.linalg.norm(x - y, ord=p)
```

#### R
```r
(sum(abs(x - y)^p))^(1/p)
```
