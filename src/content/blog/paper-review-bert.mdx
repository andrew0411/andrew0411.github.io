# BERT: Pre-training of Deep Bidirectional Transformers

**BERT** (Bidirectional Encoder Representations from Transformers) is a landmark NLP model introduced by Google AI in 2018. In this review, we summarize the key ideas:

- BERT uses a **masked language modeling** objective and **next sentence prediction** for pre-training.
- It achieved state-of-the-art performance on many NLP tasks by enabling **bidirectional context** in encoding.

## Key Contributions

1. **Bidirectional Pre-training:** Unlike previous models like GPT which are unidirectional, BERT learns from both left and right context.
2. **Transformers:** BERT builds on the Transformer architecture (Vaswani et al. 2017) and demonstrates its versatility in language understanding.

## Equations and Math

The loss function for masked language modeling is the cross-entropy between the predicted token distribution and the true token. For example, a simple formula: $L = -\sum_{t} \log P(x_t | X_{\setminus t})$.

## Conclusion

BERT opened the door to a new era of NLP models (the Transformer era), and techniques like fine-tuning on pre-trained models became the norm.

# Sample code: (just for illustration)
import torch
from transformers import BertTokenizer, BertModel

tokenizer = BertTokenizer.from_pretrained('bert-base-uncased')
model = BertModel.from_pretrained('bert-base-uncased')

outputs = model(**inputs)
